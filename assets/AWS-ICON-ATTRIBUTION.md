# Architecture diagram assets

`davdeploy-cloud-pilot.drawio` is the editable source for the checked-in SVG topology. The rendered topology uses the checked-in service icons in `assets/aws-icons/`.

Icons were selected from the AWS Architecture Icons package published on **2026-07-31**: [AWS icon package](https://d1.awsstatic.com/onedam/marketing-channels/website/public/shared/architecture-icon-release/Icon-package_07312026.5846e92413caa21490223536cc97f1269e44fa92.zip). They remain AWS assets; this repository includes only the six SVGs needed for the planned topology: Application Load Balancer, EKS, ECR, RDS, Secrets Manager and S3.

Source and usage guidance: [AWS Architecture Icons](https://aws.amazon.com/architecture/icons/). Keep this record updated if the selected icon package changes.
