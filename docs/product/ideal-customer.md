# Ideal Customer

The first user is an AI founder, backend engineer, ML engineer or AI engineer on a 2–20 person team. They already have an AI application, GitHub and AWS, but do not have enough platform, DevOps or ML-infrastructure capacity.

The user adopts bottom-up. Later buyers differ:

- **Growth buyer:** CTO, VP Engineering or Head of Engineering.
- **Security buyer:** CISO, compliance or platform leader.

Enterprise buyers matter, but enterprise procurement is not the only path to early adoption.
