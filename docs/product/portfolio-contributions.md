# What the public reference repositories contribute

AgentConstruct is the private commercial product. The public repositories remain separate evidence and are not merged wholesale.

| Reference repository | Pattern used here or reserved for later |
| --- | --- |
| `ai-platform-control-plane` | Governed plans, approvals, audit, bounded execution, observation and destroy |
| `multi-tenant-ai-inference-platform` | Future model routing, quotas and metering |
| `ai-developer-platform` | Self-service developer experience and ownership ideas |
| `ai-observability-finops-platform` | Future AI telemetry, SLO and cost evidence |
| `model-deployment-control-plane` | Future release, canary and rollback controls |
| `secure-mcp-infrastructure-gateway` | Governed tool boundaries and delegated authority |
| `ai-infrastructure-auto-remediation-agent` | Future bounded remediation patterns |
| `secure-agent-runtime` | Future sandbox and secret-minimisation patterns |
| `gpu-scheduler-lab` | Future accelerator capacity and fairness ideas |
| `hybrid-ai-edge-platform` | Later edge-placement concepts |

Only the local product code and evidence in this repository count as AgentConstruct implementation. A reference repository does not make a capability executed here.
