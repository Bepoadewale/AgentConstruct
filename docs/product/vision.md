# Product Vision

**From AI code to governed production infrastructure.**

A small AI team connects its code and cloud, describes what it needs, reviews the recommendation, and approves one exact deployment plan. davdeploy handles the infrastructure choices behind that outcome while keeping important decisions visible.

The first customer workflow is an AI API or RAG application that needs staging and production, private data handling, bounded traffic, monitoring and a monthly budget. The planner starts with the simplest safe AWS option, not EKS by default. V1 is AWS-first, but interfaces do not assume AWS forever.
