# ADR-001: davdeploy is the private commercial flagship

## Context

The repository was strategy-only while public projects proved individual platform patterns.

## Decision

Build davdeploy here as the integrated private commercial product.

## Alternatives

Keep this repository strategy-only, or make a public inference project the commercial root.

## Consequences

Private commercial reasoning stays private; public repositories remain evidence. Product work must still be reproducible and truthful.

## Security and operations

The private product does not receive a weaker security standard. Local fixtures and customer-cloud boundaries must be explicit.
